## 2. 기업 확인 질문

### 2.1 ERP·데이터
1. ERP를 쓰는가? 제품명·버전, 생산계획(MRP) 기능을 쓰는가?
2. 제품·자재·BOM·주문·재고·생산능력의 실제 테이블·키·코드 체계는? 업체 코드 ↔ 사내 코드 대응표는 누가 관리하는가?
3. 데이터 반입 방식: 파일 업로드 / 공식 API / 중간 DB? 직접 DB 쓰기는 금지인가? 테스트용 sandbox가 있는가?
4. BOM 버전·유효기간·사이트 구분을 어떻게 관리하는가? (사이트가 여럿이면 E10 SC1처럼 데이터 이전 필요)
5. 생산능력을 시간 단위로 관리하는가, 수량 단위로 관리하는가? 환산 기준은?

### 2.2 승인·업무 규칙
6. ERP 반영 전 승인 절차(1인/2인, 권한, 감사 로그 보존 기간)는?
7. 자동 반영을 허용할 필드·조건이 있는가? (현재 기본값: 전부 검토)
8. 필수 납기의 정의, 외주 가능 여부·외주처 능력·자재 제공 조건, 안전재고 정책은?
9. E05 합성 가정 규칙(라인 없는 BOM, 같은 구성품 중복, 외주 불가 제품의 외주 라인 등)이 실제 규칙인가?

### 2.3 문서
10. 주로 받는 문서 형식과 비율 (CSV/XLSX/PDF/스캔/HWP/DOCX/PPTX)? 스캔 문서 비율은?
11. 업체별 서식이 고정인가? 같은 행에 코드와 품명을 함께 적는가? (M13 유형 충돌 빈도)

### 2.4 환경·보안
12. 서버 사양(CPU·메모리·GPU), OS, 인터넷 연결 여부, 사내망 정책은?
13. 외부 API로 문서를 보낼 수 있는가? 승인 절차, 데이터 보존·재학습 정책 확인 책임은?
14. 장애 시 허용 지연(문서 처리가 몇 시간 늦어져도 되는가)과 월간 문서 처리량은?
15. 설치 가능 소프트웨어 제한(Python·SQLite·Java 등), 라이선스 정책(AGPL 등)은?
