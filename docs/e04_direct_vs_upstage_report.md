## 6. 잠정 판단 (본 실험 전)

| 관찰 (실측) | 의미 |
|---|---|
| 텍스트형 PDF 두 건에서 셀 텍스트·구조는 pdfplumber v2와 Upstage가 같음 | 텍스트형 PDF만 보면 API의 정확도 이익은 **관찰되지 않음** |
| 병합 셀은 Upstage HTML이 우세(4/6 vs 2/6, 1개 문서) | 병합이 많은 복잡 표에서 API 이점 가능성 — 표본 1개라 일반화 불가 |
| Upstage는 셀 좌표를 주지 않음 | 셀 단위 원본 추적(E10 원본 추적 가능률)에서 직접 파서가 유리 |
| Upstage 1회 8~10 s·쪽당 비용 / 직접 파서 0.04~1.6 s·비용 0 | 처리량·비용은 직접 파서 우세. 단 API 시간은 네트워크 포함 1회값 |
| 스캔 PDF·OCR 미측정 | API의 본래 강점이 예상되는 영역이 비어 있음 — 판단 보류의 주된 이유 |

판정: Upstage Document Parse **보류 (조건부 검토 후보)** — 직접 파서로 실패하는 스캔·복잡 병합 표 문서에 한해 비교가 필요. 직접 파서(pdfplumber v2) **조건부 채택** 후보 (텍스트형 PDF, 사람 검토 전제).
